# 🌍 Global Adventure AI – 2026 Travel Planner

Global Adventure AI is a simple **HTML, CSS, and JavaScript based travel planner** that generates a basic travel itinerary for different countries.  
Users can select a destination, travel date, and trip duration to generate a day-by-day adventure plan.

---

## ✨ Features

- 🌎 Enter any country to generate a travel plan
- 📅 Select travel date
- ⏳ Choose trip duration (3, 5, 7, or 10 days)
- 🗺️ Automatic itinerary generation
- 💰 Estimated travel budget calculation
- ☁️ Simulated weather information
- 🎒 Adventure activities for each day
- 📱 Responsive modern UI with glassmorphism design

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page  
- **CSS3** – Styling and animations  
- **JavaScript (Vanilla JS)** – Travel plan generation logic  
- **Unsplash** – Background travel image
